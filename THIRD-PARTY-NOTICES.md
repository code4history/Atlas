# Third-party notices

`@c4h/atlas` itself is under the MIT License (see `LICENSE` in the repository and the `license`
field of `package.json`). The npm package also redistributes, unchanged, runtime files of
[proj-wasm](https://github.com/willcohen/clj-proj) 0.1.0-alpha8 so that an application can serve
them next to its own code:

| File in `dist/` | What it is |
|---|---|
| `proj-emscripten.wasm` | PROJ compiled to WebAssembly, with the libraries it is built on (SQLite, libtiff, zlib) |
| `proj-emscripten.js` | The loader generated by Emscripten for that WebAssembly module |
| `proj-worker.mjs`, `fetch-worker.mjs` | The worker scripts of proj-wasm |
| `proj.db` | The coordinate system database of PROJ |
| `proj.ini` | The default settings file of PROJ |

The notices of these components follow. The licence texts of PROJ, libtiff and zlib are quoted
as proj-wasm 0.1.0-alpha8 ships them in its README.

## Data in proj.db

`proj.db` is built by the PROJ project (version 9.8.1) from the registries below; the versions are
the ones recorded in the `metadata` table of the file.

- **EPSG Geodetic Parameter Dataset** v12.029 (2025-10-02), owned by the International Association
  of Oil & Gas Producers (IOGP). Its use is subject to the EPSG terms of use:
  <https://epsg.org/terms-of-use.html>. The data in `proj.db` has been converted to the PROJ
  database format and is not the EPSG Dataset as published by IOGP.
- **ESRI** projection engine database (ArcGIS Pro 3.6, 2025-12-01), published by Esri under the
  Apache License 2.0: <https://github.com/Esri/projection-engine-db-doc>.
- **IGNF** registry v3.1.0 (2019-05-24) of the Institut national de l'information géographique et
  forestière (IGN France).
- **NKG** transformations v1.0.w (2025-02-13) of the Nordic Geodetic Commission:
  <https://github.com/NordicGeodesy/NordicTransformations>.
- Definitions of the **OGC** and **IAU_2015** authorities and of PROJ itself, which come with PROJ
  under the PROJ terms above.
